# Lashlume — Shopify thema

Thema voor een webshop met lash studio-inrichting (lash beds, zadelstoelen, lampen, accessoires).
Stijl: zacht en afgerond (DM Sans, pill-knoppen, grijze kaarten), met een uitgebreide productpagina: kleurstalen, voorraadstatus, kenmerkenkaartjes, uitklapblokken, donkere FAQ en een vaste koopbalk op mobiel.

Upload de map als zip via Shopify admin > Webshop > Thema's, of gebruik `shopify theme push`.
Kleuren, lettertypen en afronding pas je aan onder Thema-instellingen.
